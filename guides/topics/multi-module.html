Multi-module projects

Build several projects together, share configuration and build part of them.

How-to guides

Directions for a specific goal.

  • Split a project into modules Turn one Maven project into a parent POM with modules that depend on each other and build together from the root directory.
  • Build part of a multi-module project Build one module, a module with the modules it needs or with the modules that use it, leave modules out, or resume a failed build.
  • Share dependency versions and plugin configuration Set dependency versions, plugin versions and plugin configuration once in the parent POM, and import a BOM, so that every module uses the same.

Reference

Files, elements, options and settings, described.

  • Reactor options The command-line options that select, order and continue the modules of a multi-module build, the project selector syntax, and the Maven line each needs.

Explanation

Why Maven works the way it does.

  • Aggregation and inheritance How a parent POM passes configuration down, how an aggregator builds modules together, and how the reactor decides the order.
