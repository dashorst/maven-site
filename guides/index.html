Maven guides

Using and configuring Apache Maven 3.9 and 3.10, and what the upcoming Maven 4.0 changes.

/

A demonstration: four topics of the Maven documentation, rewritten as separate tutorials, how-to guides, reference and explanation pages, so that each page does one job and search can find the section that answers a question. The search covers the whole site. The pages these were written from are still there, and say which pages replace them. See GUIDE.md for how the guide is written.

Start here

Lessons that take you from an empty directory to a tested, packaged project.

  1. Create your first project Check Java and Maven, generate a project from the quickstart archetype, build it into a JAR, run its test and run the program.
  2. Add a dependency and a test Use a library from Maven Central in your project, test the code that uses it with JUnit, and see which libraries Maven brought in.

Topics

Each topic gathers its tutorials, how-to guides, reference and explanation on one page.

  • Getting started 4 pages Install Maven, create a project and build it.
  • Configure Maven 6 pages Settings, repository mirrors, proxies and credentials.
  • Multi-module projects 5 pages Build several projects together, share configuration and build part of them.
  • JDKs and toolchains 4 pages Build with a JDK other than the one Maven runs on.

Or list every page of one kind: tutorials, how-to guides, reference, explanation.

Look it up

  • A–Z index Every file, element, option and plugin the guide explains, and every page by title.
  • POM reference Every element of pom.xml.
  • Settings reference Every element of settings.xml.
  • Command-line options Every option of mvn, generated from the Maven source of each release.
  • Lifecycles The phases of the default, clean and site lifecycles, generated from the Maven source.
  • Plugins The plugins of the Maven project, each with its goals and parameters.
