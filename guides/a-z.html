All pages

  • Add a dependency and a test Tutorial Use a library from Maven Central in your project, test the code that uses it with JUnit, and see which libraries Maven brought in.
  • Aggregation and inheritance Explanation How a parent POM passes configuration down, how an aggregator builds modules together, and how the reactor decides the order.
  • Build part of a multi-module project How-to Build one module, a module with the modules it needs or with the modules that use it, leave modules out, or resume a failed build.
  • Build with a different JDK than Maven runs on How-to Compile, test and package a project with a JDK of your choice while Maven itself keeps running on the JDK in JAVA_HOME.
  • Compile for an older Java version How-to Build classes that run on an older Java than the JDK you build with, check them against that Java's API, and run the tests on it.
  • Configuration files and variables Reference Every file and environment variable Maven reads its configuration from, with location, scope and Maven line, and the patterns of mirrorOf.
  • Connect through an HTTP proxy How-to Make Maven download through the HTTP proxy your network requires, with a login if the proxy asks for one and exceptions for internal hosts.
  • Create your first project Tutorial Check Java and Maven, generate a project from the quickstart archetype, build it into a JAR, run its test and run the program.
  • Encrypt passwords in settings.xml How-to Replace the plain passwords of servers and proxies in settings.xml with encrypted values, with a master password on Maven 3 or mvnenc on Maven 4.
  • Phases, goals and plugins Explanation How Maven turns a command such as mvn package into a series of plugin goals, and why every Maven project builds with the same few commands.
  • Reactor options Reference The command-line options that select, order and continue the modules of a multi-module build, the project selector syntax, and the Maven line each needs.
  • Share dependency versions and plugin configuration How-to Set dependency versions, plugin versions and plugin configuration once in the parent POM, and import a BOM, so that every module uses the same.
  • Split a project into modules How-to Turn one Maven project into a parent POM with modules that depend on each other and build together from the root directory.
  • Standard directory layout Reference The directories and files of a Maven project, what goes in each, and which plugin reads or writes it.
  • Store credentials for a repository How-to Give Maven the username and password for a repository it downloads from or deploys to, matched to the repository by id.
  • Toolchains and the JDK Maven runs on Explanation Why Maven keeps the JDK it runs on apart from the JDK that compiles and tests your code, how plugins find that JDK, and how it differs from release.
  • Use a repository manager as a mirror How-to Send every download through your organisation's repository manager instead of Maven Central and the repositories projects declare.
  • Where Maven reads its configuration Explanation Why Maven splits its configuration between the project and the machine, which files and variables each side uses, and how they combine.
  • toolchains.xml Reference Where Maven reads toolchains.xml, the elements of a JDK toolchain, how a requirement matches an entry, and which plugins use the selected toolchain.
