• 1. Create your first projectCheck Java and Maven, generate a project from the quickstart archetype, build it into a JAR and run the program.
  • 2. Add your first dependencyFind a library on Maven Central, add it to your project's POM, use it in your code and run the program with it.
  • 3. Add and configure your first pluginAdd the Shade plugin to your build, bind its goal to a phase and configure it, so that your program runs with java -jar.
  • 4. Test and build your projectTest your code with JUnit, see what a failing test does to the build, then verify the project and install it in your local repository.
  • 5. Split your application into modulesTurn my-app into a parent POM with a library module and an application module, build them together, and build one with what it needs.
